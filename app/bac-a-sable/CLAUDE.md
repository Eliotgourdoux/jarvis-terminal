# Bac à sable des tests de l'app Better Terminal (sessions de test automatiques)

Ce dossier ne sert qu'aux tests automatiques de l'app. Personne ne lit ces sessions en direct.
Ces règles l'emportent sur les consignes globales pour toute session lancée ici :

- N'utilise aucun outil, sauf si le message le demande explicitement (et alors seulement celui-là).
- N'exécute jamais `prevenir.sh`, `todo`, `beeper-say.sh`, `tg-*.sh`, `terminal-notifier`, `osascript`, ni aucun outil Beeper ou MCP : ni Telegram, ni notification, ni rappel.
- Pas de `todo list` en début de session.
- Réponds court, en français.
